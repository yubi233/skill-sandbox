# ARCANA 元素技能实验室

直接打开根目录 `element-skill-sandbox.html`。页面内联 Babylon.js 和所有程序化资源，无 CDN、无模型下载，离线可用。

## 操作

- **1–8**：选择八种技能。
- **[ / ]**：切换当前技能的 1–5 级，也可点击等级条。
- **空格 / 释放按钮**：向镜头前方的可见落点释放。
- **鼠标左键**：向地面指针落点释放。
- **WASD**：移动；**右键拖动**：旋转镜头；**滚轮**：缩放。
- **Esc / 右键轻点**：取消选择、未完成蓄力及自动演示。已释放的法术继续完成。
- **实时参数 → 展开**：修改当前技能、当前等级的粒子密度、规模、速度和周期。颜色在该技能全部等级共享，其余四项每级独立保留。
- **自动演示**：按各技能已选等级轮播，每招完整结束后再切下一招。

## 源码与构建

```sh
node dev/build.mjs
```

构建将 `dev/page.html.src`、`dev/vendor/babylon.js` 和五个 JS 源码片段内联回根目录页面。请编辑 `dev/` 源码后构建，不要只改生成的 HTML。

### AI 贴图素材管线

`dev/assets/*.png` 会在构建时以 base64 内联为 `window.__TEX_PNG`，运行时解码后**原位升级**同名程序化贴图（无图时自动回退程序化版本，缺素材不影响构建）。现有素材：

| 文件 | 贴图键 | 用途 |
| --- | --- | --- |
| `meteor-scar.png` | `meteorScar` | 陨火天降余波地面焦痕 |
| `rune.png` | `rune` | 施法法阵/落点法阵（全部技能 + 试炼场地面，8 重旋转对称） |
| `ice-scar.png` | `iceScar` | 冰系余波（寒霜之矛、冰川王冠） |
| `volt-scar.png` | `voltScar` | 雷系余波（雷霆之矛、伏特禁城） |
| `earth-scar.png` | `earthScar` | 岩系余波（岩牙突刺） |

新增素材三步：

```sh
# 1. 生成（提示词放 dev/assets-raw/prompts/<名>.txt，用 mimo-image skill 提交）
bash dev/tools/gen.sh <名> high
# 2. 后处理：水印角补丁 + 亮度键抠底 + 白光alpha (+ --symmetry=N 旋转对称)
python3 dev/tools/postprocess_tex.py dev/assets-raw/<名>-raw.png dev/assets/<名>.png
# 3. 构建
node dev/build.mjs
```

后处理的硬约定：输出 RGB 必须纯白（技能经 `uColor` 染色），结构压进 alpha；平台水印在右下角，靠旋转180°左上角补丁覆盖，旋转对称化必须放在补丁之后、alpha 推导之前不允许。

## 本次验证

- 所有源文件通过 `node --check`；生成 HTML 无未替换占位符。
- 浏览器内手动步进验证 **8 × 5 = 40** 种组合，五阶段都完成，无运行时异常。
- 每次结束并清理后，网格、材质、变换节点回到场景基线，粒子为零。
- 八种五级法术均经过实际 WebGL 渲染检查，无着色器错误。
- 已验证等级参数隔离、在飞行法术的等级锁定、Esc 取消、WASD 移动、失焦清键、重置及镜头缩放复位。
- 在 1440×900 和 390×844 检查界面布局；窄屏技能栏与展开的编辑器均在视口内。
- 内嵌浏览器可能在页面可见时暂停 RAF；仅在 RAF 停滞超过 250ms 时以定时器补帧，隐藏页面不补帧。测试时可设 `__game.renderPaused = true` 暂停自动渲染，然后用 `engine.beginFrame(); game.tick(dt); engine.endFrame();` 手动推进。

- 内嵌浏览器截图接口多次超时，视觉检查限于 WebGL 读回、投影坐标与布局边界；没有把不稳定的截图结果当作完整视觉验收。

性能数字依设备与浏览器而变；本次不把内嵌浏览器的节流帧率当作真实性能基准。
