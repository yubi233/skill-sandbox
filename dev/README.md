# ARCANA 元素技能实验室

直接打开根目录 `element-skill-sandbox.html`。页面内联 Babylon.js 和所有程序化资源，无 CDN、无模型下载，离线可用。

## 操作

- **1–9 / 0 / -**：选择十一种技能。
- **[ / ]**：切换当前技能的 1–5 级，也可点击等级条。
- **空格 / 释放按钮**：向镜头前方的可见落点释放。
- **鼠标左键**：向地面指针落点释放。
- **右上角「复制镜头」**：把当前镜头参数（alpha/beta/半径/视场/目标点/相机位置）复制为单行 JSON。
- **WASD**：移动；**右键拖动**：旋转镜头；**滚轮**：缩放。
- **Esc / 右键轻点**：取消选择、未完成蓄力及自动演示。已释放的法术继续完成。
- **实时参数 → 展开**：修改当前技能、当前等级的粒子密度、规模、速度和周期。颜色在该技能全部等级共享，其余四项每级独立保留。
- **自动演示**：按各技能已选等级轮播，每招完整结束后再切下一招。
- **系别展示**：技能栏按洛克世界系别分组排序，卡片右下角标系别，简介卡显示系别徽标。

## 系别体系（洛克世界 18 系）

元素采用《洛克王国：世界》手游的 18 系属性体系（定义在 `dev/skill-catalog.js` 的 `ELEMENTS`）：
普通/草/火/水/光/地/冰/龙/电/毒/虫/武/翼/萌/幽/恶/机械/幻。与老页游口径的差异：土+石合并为地、幽灵→幽、恶魔→恶、新增幻、删除神火/神水/神草三神系。当前十一技能归属：

| 系别 | 技能 |
| --- | --- |
| 普通系 | 魔弹连射 |
| 水系 | 怒涛裂岸 |
| 火系 | 陨火天降 |
| 电系 | 雷霆之矛、伏特禁城 |
| 冰系 | 寒霜之矛、冰川王冠 |
| 地系 | 岩牙突刺 |
| 翼系 | 疾风裂空（洛克世界无独立风系，翼系即飞行/风位） |
| 光系 | 星光束、王之财宝（洛克世界无圣系，光系承担圣位） |

草/龙/幻等其余 10 系为预留位，新技能在注册项写 `element` 键即可归系；系别 key 与展示名、徽标色都在 `ELEMENTS` 一处维护。技能栏按系别 order 分组排序，快捷键仍绑定技能 id 不受展示顺序影响。

## 五级大法术

### 五阶语法

区分度不是靠放大尺寸得来的。参照王之财宝的五级设计，全部十一技能统一套用一套**时空双重语法**，每一级至少落一个肉眼可辨的结构差异：

| 阶 | 名 | 空间位置 | 时间编排 | 独占标志 |
| --- | --- | --- | --- | --- |
| L1 | 初阶 | 施法者本体 / 手中 | 单体单发 | — |
| L2 | 进阶 | 仍在弹道上 | **分裂或链式跳转** | 时序错峰 |
| L3 | 高阶 | **跃迁到落点** | 悬停后释放 | 落点法印 / 轨道 |
| L4 | 领域 | **垂直维度打开** | 分批轮番 | 立体包裹 |
| L5 | 灾厄 | **超大结构回归** | **多轮 / 持续编排** | 全等级独占主体 |

数值倍率（LEVEL_SCALE）退为辅助读数，不再是相邻级的主要差别。

| 技能 | L1 → L5 形态跃迁 | 结构分野点 |
| --- | --- | --- |

## 源码与构建

```sh
node dev/build.mjs
```

构建将 `dev/page.html.src`、`dev/vendor/babylon.js` 和六个 JS 源码片段内联回根目录页面（加载顺序即清单顺序：particles → skill-catalog → core → skills → ui → main）。请编辑 `dev/` 源码后构建，不要只改生成的 HTML。

构建失败策略：贴图素材**目录缺失**只是警告并回退程序化贴图；**目录存在但任一文件读取失败**、**文件名折叠出同名贴图键**、**占位符未替换**都会让构建直接失败，绝不静默丢失素材。

## 架构要点

- **技能唯一注册表** `dev/skill-catalog.js`：名称/系别/颜色/默认等级/射程/描述/演示顺序等元数据只在这一处维护。`core.js` 默认参数、`ui.js` 技能栏与高阶描述、`main.js` 快捷键上限与演示顺序全部由表派生；`skills.js` 侧校验「注册项 ↔ Cast 实现 ↔ 默认参数」三者闭合（`SKILLS.validateRegistry()`，启动时自动运行，测试覆盖）。新增技能 = 一个注册项 + 一个 Cast 子类。
- **施法可回滚**：`Cast` 构造函数只做无副作用快照，场景资源全部在 `init()` 分配；`SKILLS.start` 对「构造+init」整体 try/catch，失败即 dispose 回收并置 `lastRejectReason='error'`，不产生半初始化残留。
- **逐实例异常隔离**：`SKILLS.update` 逐个 try/catch 法术与瞬态，单个故障只回收自身并记入 `console.error`（页面 `__errors` 可查），不拖垮其余法术与整帧渲染。
- **位移与姿态分离仲裁**：姿态跟随最新施法（`poseOwner`）；位移只由声明 `controlsMovement` 的法术驱动（`moveOwner`）——疾风位移途中施放其他法术，位移继续到目标，不会被截断。
- **显式主循环**：`game.tick` 按流水线依次调用 `game.update`（时间+移动，`FX.time` 唯一写入点）→ 技能 → 粒子 → `game.lateUpdate`（姿态/镜头/装饰）→ UI → `game.render`（动态分辨率按真实帧间隔评估）。模拟不再藏在 `scene.onBeforeRenderObservable` 里。
- **UI/输入经 game API**：取消走 `SKILLS.cancelPendingCasts(game)`、清冷却走 `SKILLS.clearCooldowns()`，UI 不再直接改写 casts/冷却字典，也不向技能实例写缓存字段。
- `game.dispose()` 统一回收：渲染循环、补帧 watchdog、resize 监听、技能、场景、引擎，幂等。

| `gold-scar.png` | `goldScar` | 金系余波（王之财宝） |

| `blade.png` | `blade` | 宝库飞剑剪影（王之财宝宝具精灵） |
| `spear-blade.png` | `spearBlade` | 宝库飞枪剪影（王之财宝宝具精灵） |
| `grand-circle.png` | `grandCircle` | 超大型召唤法阵（王之财宝五级脚底法阵，8 重旋转对称） |

新增素材三步：

```sh
# 1. 生成（提示词放 dev/assets-raw/prompts/<名>.txt，用 mimo-image skill 提交）
bash dev/tools/gen.sh <名> high
# 2. 后处理：水印角补丁 + 亮度键抠底 + 白光alpha (+ --symmetry=N 旋转对称)
python3 dev/tools/postprocess_tex.py dev/assets-raw/<名>-raw.png dev/assets/<名>.png
# 3. 构建
node dev/build.mjs
```

后处理的硬约定：输出 RGB 必须纯白（技能经 `uColor` 染色），结构压进 alpha；平台水印在右下角，靠绕画布中心旋转 90° 的同半径带补丁覆盖（内缘羽化消接缝），旋转对称化必须放在补丁之后、alpha 推导之前不允许。
